## ✨ 简介

一个用于教学演示的 C# 多模块解决方案：主程序负责统一入口，各功能模块独立成项目，自带独立测试入口，便于逐模块学习、运行与调试。

| | 特点 |
| :---: | :--- |
| 🧱 | 主程序 + 多模块的标准 `.sln` 组织方式 |
| 🧪 | 每个模块自带独立测试入口 |
| 🛠️ | 提供模块创建脚本，快速扩展新模块 |
